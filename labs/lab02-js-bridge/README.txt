JavaScript สำหรับผู้ที่มาจาก C และ Java
=====================================================

ขั้นตอน
  1. แตกไฟล์ zip นี้ไว้ที่ไดรฟ์ D หรือที่ใดก็ได้ที่พาธไม่มีภาษาไทย
  2. เปิด Command Prompt เข้าไปในโฟลเดอร์ lab02-js-bridge
  3. พิมพ์   npm ci        (ครั้งแรกครั้งเดียว)
  4. พิมพ์   npm run check (ดูว่าข้อไหนยังไม่ผ่าน)

งานที่ต้องทำ
  แก้เฉพาะไฟล์ src/bridge.js เท่านั้น
  ต้นฉบับภาษา C ที่ต้องแปลอยู่ใน reference/original.c
  ชื่อของแต่ละเทสต์คือโจทย์ของข้อนั้น

กฎสองข้อที่ใช้กับทั้งไฟล์
  1. ฟังก์ชันที่รับอาร์เรย์หรือออบเจกต์เข้ามา ห้ามแก้ของที่รับเข้ามา
  2. เปรียบเทียบค่าด้วยตัวดำเนินการที่ไม่แปลงชนิดข้อมูลให้อัตโนมัติ

สิ่งที่ส่ง
  ไฟล์ src/bridge.js ไฟล์เดียว อัปโหลดเข้า Google Classroom
  ไม่ต้องบีบอัด ไม่ต้องส่งทั้งโปรเจกต์ ไม่ต้องส่ง node_modules

ติดปัญหาที่ไม่เกี่ยวกับโจทย์ เช่น npm ไม่ทำงาน
  ถามในช่องความคิดเห็นของงานนี้ใน Classroom
