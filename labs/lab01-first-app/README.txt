แอปแรกของฉัน รันบนอุปกรณ์จำลอง
=====================================================

โฟลเดอร์นี้คือเครื่องมือตรวจงาน ไม่ใช่ตัวโปรเจกต์
โปรเจกต์ให้สร้างเองตามใบแล็บ แล้ววางโฟลเดอร์นี้ไว้ข้าง ๆ กัน เช่น

  D:\mobile\
      lab01-first-app\      <- โฟลเดอร์นี้
      my-first-app\         <- โปรเจกต์ที่สร้างเอง

ไฟล์ที่ต้องใช้
  1-CHECK-PC.bat     ดับเบิลคลิก  ตรวจว่าเครื่องพร้อมหรือยัง (ทำก่อนเริ่ม)
  2-CHECK-WORK.bat   ดับเบิลคลิก  ตรวจงานของตัวเอง (ทำก่อนส่ง)

ถ้าโปรเจกต์ไม่ได้อยู่ข้าง ๆ กัน ให้เปิด Command Prompt แล้วพิมพ์
  npm run check -- D:\mobile\my-first-app

สิ่งที่ส่ง
  ภาพหน้าจอ screenshot.png ที่เห็นแอปของตัวเองรันอยู่ และมีรหัสนิสิตบนหน้าจอ
  อัปโหลดเข้า Google Classroom หัวข้อ "ปฏิบัติการที่ 1"

หมายเหตุสำหรับเครื่องในห้องแล็บ
  ให้เก็บงานไว้ที่ไดรฟ์ D หรือ OneDrive ไม่ใช่ Desktop
  เพราะบางเครื่องล้างโปรไฟล์ผู้ใช้ทุกครั้งที่ออกจากระบบ

ถ้า npm เรียกไม่ได้ ให้ใช้ Command Prompt ไม่ใช่ PowerShell
