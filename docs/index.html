ทุกสัปดาห์มีโปรเจกต์ตั้งต้นพร้อมตัวตรวจงาน สั่ง npm run check แล้วจะเห็นทันทีว่าข้อไหนผ่าน ข้อไหนยังไม่ผ่าน ชื่อของแต่ละเทสต์คือโจทย์ของข้อนั้น รันซ้ำได้ไม่จำกัดครั้ง คะแนนคิดจากจำนวนข้อที่ผ่านตอนปิดส่ง

เก็บงานไว้ที่ไดรฟ์ D หรือ OneDrive ไม่ใช่ Desktop เพราะเครื่องในห้องบางตัวล้างโปรไฟล์ผู้ใช้ทุกครั้งที่ออกจากระบบ และถ้า npm บอกว่าสคริปต์ถูกปิดไว้ ให้เปลี่ยนจาก PowerShell ไปใช้ Command Prompt
