แอปแรกของฉัน รันบนอุปกรณ์จำลอง

จบคาบนี้ทุกคนต้องมีแอปของตัวเองรันอยู่จริงหนึ่งตัว ไม่ใช่เพราะแอปนั้นมีประโยชน์อะไร แต่เพราะแล็บอีกสิบสี่สัปดาห์ที่เหลือเริ่มจากจุดนี้ทั้งหมด

01จบสัปดาห์นี้ต้องทำอะไรได้

  • สร้างโปรเจกต์ Expo ใหม่จากศูนย์ และเปิดให้รันบนอุปกรณ์จำลองของ Android Studio ได้ด้วยตัวเอง
  • แก้ข้อความบนหน้าจอแล้วเห็นผลเปลี่ยนทันทีโดยไม่ต้องปิดเปิดแอปใหม่
  • บอกความต่างระหว่างการพัฒนาแบบเนทีฟ ไฮบริด และข้ามแพลตฟอร์มได้
  • แก้ปัญหาเครื่องเบื้องต้นได้เอง เมื่อ npm เรียกไม่ได้หรืออุปกรณ์จำลองไม่บูต

02ก่อนเริ่ม ตรวจเครื่องก่อน

ดาวน์โหลดชุดเครื่องมือด้านล่าง แตกไฟล์ไว้ที่ไดรฟ์ D แล้วดับเบิลคลิก 1-CHECK-PC.bat ต้องผ่านครบ 6 ข้อก่อนทำขั้นต่อไป ข้อที่ไม่ผ่านตัวโปรแกรมจะบอกวิธีแก้ให้เอง

D:\mobile\lab01-first-app> npm run check-env ปฏิบัติการที่ 1 — ตรวจความพร้อมของเครื่อง ✓ Node.js เวอร์ชัน 22.11.0 ✓ npm เวอร์ชัน 10.9.0 ✓ พบ Java ✓ พบ Android SDK ✓ เรียก adb ได้ ✗ ยังไม่มี AVD ทางแก้: เปิด Android Studio ไปที่ Device Manager แล้วสร้างอุปกรณ์จำลองเป็นมือถือ เช่น Pixel 7 ผ่าน 5 จาก 6 ข้อ

03ขั้นตอน

เปิดอุปกรณ์จำลองค้างไว้ก่อน แล้วค่อยรัน npm run android ครั้งแรกจะใช้เวลาหลายนาที ระหว่างรอห้ามปิดหน้าต่าง

รันทีละบรรทัดใน Command Prompt ไม่ใช่ PowerShell D: cd D:\mobile npx create-expo-app@latest my-first-app --template blank cd my-first-app npm run android code . # เปิด VS Code ที่โฟลเดอร์นี้

เมื่อแอปขึ้นแล้ว เปิดไฟล์หน้าจอแรกใน VS Code แก้ข้อความ แล้วกดบันทึก ให้มองที่อุปกรณ์จำลอง ข้อความจะเปลี่ยนเองภายในไม่กี่วินาที ไม่ต้องสั่งอะไรเพิ่ม

04ปฏิบัติการประจำสัปดาห์

แก้หน้าจอแรกให้ครบสามอย่าง แล้วดับเบิลคลิก 2-CHECK-WORK.bat เพื่อดูว่าผ่านหรือยัง

ข้อสิ่งที่ต้องทำ
1แสดงรหัสนิสิตสิบหลักของตัวเองบนหน้าจอ
2ลบประโยคตัวอย่างที่ Expo ใส่มาให้ออกให้หมด แล้วเขียนข้อความของตัวเองแทน
3จับภาพหน้าจอตอนแอปรันอยู่ บันทึกชื่อ screenshot.png ไว้ในโฟลเดอร์โปรเจกต์

ดาวน์โหลดไฟล์ของสัปดาห์นี้ และส่งงานที่ Google Classroom หัวข้อ ปฏิบัติการที่ 1

lab01-first-app.zipชุดเครื่องมือตรวจงาน ไม่ใช่ตัวโปรเจกต์ โปรเจกต์ให้สร้างเอง 01418342-lab01-sheet.pdfใบแล็บหนึ่งหน้า สิ่งที่ต้องส่ง และเกณฑ์คะแนน

05ถ้าติด ให้ดูตรงนี้

อาการที่เห็นให้ย้อนไปดูตรงไหน
npm บอกว่าสคริปต์ถูกปิดไว้หน้าต่างที่เปิดอยู่เป็น PowerShell หรือ Command Prompt
แอปขึ้นแต่แก้ข้อความแล้วหน้าจอไม่เปลี่ยนไฟล์ที่กำลังแก้ใช่ไฟล์หน้าจอแรกของโปรเจกต์นี้หรือเปล่า และบันทึกแล้วหรือยัง
อุปกรณ์จำลองค้างที่โลโก้ Android ไม่ไปไหนตัวเร่งความเร็วของอุปกรณ์จำลองถูกเปิดไว้หรือยัง
ตัวตรวจงานบอกว่าหาโปรเจกต์ไม่เจอโฟลเดอร์ lab01-first-app วางอยู่ข้าง ๆ โปรเจกต์หรือเปล่า
เก็บงานไว้ที่ไดรฟ์ D หรือ OneDrive ไม่ใช่ Desktop เพราะเครื่องในห้องบางตัวล้างโปรไฟล์ผู้ใช้ทุกครั้งที่ออกจากระบบ
