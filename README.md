## ข้อกำหนดของ repo นี้

**ห้าม commit เฉลยและข้อสอบลงใน repo นี้** repo เป็นสาธารณะ และประวัติ git ย้อนดูได้แม้จะลบไฟล์ไปแล้ว
เฉลยแล็บ ข้อสอบกลางภาค ข้อสอบปลายภาค และคะแนนนิสิต ให้เก็บไว้ที่อื่นทั้งหมด

**ห้ามมีข้อมูลนิสิตในเว็บ** ไม่มีรหัสนิสิต ไม่มีรายชื่อ ไม่มีคะแนน การส่งงานและคะแนนอยู่ที่ Google Classroom

## เปิดและปิดเนื้อหาแต่ละสัปดาห์

ในไฟล์ `docs/index.html` การ์ดแต่ละสัปดาห์มีหน้าตาแบบนี้

```html
<a class="wk soon" href="week03.html">        <!-- ปิดอยู่ -->
<a class="wk" href="week03.html">             <!-- เปิดแล้ว -->
```

**เปิดสัปดาห์ไหน ให้ลบคำว่า `soon` ออกจาก class ของการ์ดนั้น ปิดก็ใส่กลับ** คำเดียวจบ
ป้าย "พร้อม" กับ "เร็ว ๆ นี้" และการกดได้หรือกดไม่ได้ เปลี่ยนตามเองทั้งหมด

### ข้อจำกัดที่ต้องรู้

GitHub Pages เป็นเว็บสาธารณะ **ไม่มีระบบจำกัดสิทธิ์** การปิดการ์ดเป็นแค่การซ่อนลิงก์
ไฟล์ที่ commit ขึ้นไปแล้วยังเปิดได้ด้วย URL ตรง เช่น `.../week03.html` ต่อให้การ์ดยังปิดอยู่

ถ้าต้องการซ่อนจริง ๆ (เช่นไม่อยากให้นิสิตเห็นก่อนเข้าคาบ) ให้พักไฟล์ไว้ที่ `drafts/`
ซึ่งอยู่นอก `docs/` จึงไม่ถูกเผยแพร่ แล้วย้ายเข้า `docs/` ในสัปดาห์ที่จะสอน

**การปล่อยสัปดาห์หนึ่ง จึงมีสองอย่าง** ย้ายไฟล์จาก `drafts/` เข้า `docs/` ตามตำแหน่งเดิม
และลบคำว่า `soon` ออกจากการ์ดสัปดาห์นั้นใน `docs/index.html` แล้ว commit ครั้งเดียว

สำหรับสัปดาห์ที่ 2 เรื่องนี้มีผลจริง เพราะการบรรยายออกแบบให้นิสิต**กดรันกล่องทดลองในคาบเป็นครั้งแรก**
แล้วค่อยอธิบายเข้าไปในความงง ถ้าเปิดหน้าไว้ล่วงหน้าจะเสียจังหวะตรงนั้นไป

## หลักการออกแบบสื่อของรายวิชานี้

ทุกปฏิบัติการมีตัวตรวจงานที่นิสิตรันเองได้ด้วย `npm run check`
**ชื่อของแต่ละเทสต์คือโจทย์ของข้อนั้น** ใบแล็บจึงไม่ต้องเขียนข้อกำหนดงานซ้ำ
เมื่อแก้เทสต์จึงไม่ต้องตามไปแก้ใบแล็บและหน้าเว็บ

ใบแล็บหนึ่งหน้ารับหน้าที่สี่อย่างที่เทสต์บอกไม่ได้ คือแล็บนี้ฝึกเรื่องอะไรและต่อจากแล็บไหน
กับดักที่เตรียมไว้ให้เจอ (บอกอาการ ไม่บอกคำตอบ) คำสั่งที่ต้องพิมพ์ และเกณฑ์คะแนน
