JavaScript สำหรับผู้ที่มาจาก C และ Java

ไวยากรณ์ของ JavaScript ยืมมาจาก C เกือบทั้งหมด ปีกกา เซมิโคลอน if for หน้าตาเหมือนกันจนอ่านออกตั้งแต่บรรทัดแรก สิ่งที่ไม่เหมือนกันคือสิ่งที่อยู่ในตัวแปร และนั่นคือที่มาของความผิดพลาดเกือบทั้งหมดในสัปดาห์นี้

01จบสัปดาห์นี้ต้องทำอะไรได้

  • แปลฟังก์ชันจาก C เป็น JavaScript ให้ได้ผลลัพธ์เท่าเดิมทุกกรณี รวมถึงกรณีขอบอย่างอาร์เรย์ว่างและค่าติดลบ
  • บอกได้ว่าเมธอดของอาร์เรย์ตัวไหนแก้ของเดิม ตัวไหนคืนตัวใหม่ และเลือกใช้ให้ถูกสถานการณ์
  • อธิบายได้ว่าทำไมออบเจกต์สองตัวที่ข้างในเหมือนกันถึงไม่เท่ากัน
  • เลือกตัวดำเนินการเปรียบเทียบได้ถูก โดยรู้ว่าอีกตัวแปลงชนิดข้อมูลให้เงียบ ๆ

02ลองรันดูก่อน

สี่กล่องนี้คือสี่เรื่องที่ทำให้คนจาก C และ Java พลาดบ่อยที่สุด อ่านโค้ดแล้วเขียนผลลัพธ์ที่คิดว่าจะได้ลงช่องสีเหลืองก่อน ปุ่มรันจะกดได้เมื่อเขียนแล้ว เขียนเสร็จกดรันเทียบได้เลย ที่ต้องเขียนก่อนไม่ใช่เพราะเป็นกฎ แต่เพราะถ้าเห็นคำตอบก่อน สมองจะบอกตัวเองว่ารู้อยู่แล้ว ทั้งที่ยังไม่รู้ ข้อที่เดาไม่ตรงคือข้อที่ได้ความรู้ใหม่กลับไป ทุกอย่างทำงานในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร และไม่มีการส่งข้อมูลไปที่ไหน
